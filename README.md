# UEFN Verse

Verse digests, device wiring, compile/errors, skill reader, UMG Widget Blueprint tools, and New-file system template packs (Player Core, Economy, Progression, Tycoon, UMG Widget, …). Bundles verse + islandsettings skills.

Desktop plugin for [UEFN-Ducky](https://github.com/UEFN-Ducky/UEFN-Ducky) (`verse`).
Install or update from **Settings → Store** in the app — do not install from a zip by hand.

## Build

```bash
py scripts/build_zip.py
```

Writes `deploy/verse-*.ducky-plugin.zip` (scripts/ and deploy/ are not packed).
